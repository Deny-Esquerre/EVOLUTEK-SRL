Manufacturing Platform (KMS)

Ketsol KMS is an industrial platform that acts as the plant's operating system: it connects PLCs, DCS and SCADA systems through more than 50 native connectors —Modbus, Siemens S7, Allen-Bradley, Mitsubishi MELSEC, OPC UA/DA/HDA, IEC 61850, IEC 104, DNP3, BACnet and MQTT, among others— and stores every signal as time-series history ready for analysis.

On top of that data, it provides drag-and-drop dashboards, OEE and alarm views, shift, energy and quality reports, threshold-based alerts or alerts on anomalies detected with machine learning, a rules engine that can write setpoints back to the PLC, and an AI layer that answers natural-language questions about historical data. With KMS Edge, it runs at the edge with store-and-forward, and scales from a single line to multiple plants, on-premise or in the cloud.

  1. 01

    Prerequisites

    Before installing, define the infrastructure and validate the basic requirements.

    • Windows server or PC, or an industrial gateway for KMS Edge.
    • Network connectivity to PLCs, DCS and SCADA.
    • Inventory of the equipment, protocols and tags to integrate.
  2. 02

    Installation and Licensing

    Install the platform and get the service up and running.

    • Install KMS or KMS Edge on Windows.
    • Set up the database (PostgreSQL or SQL Server).
    • Activate the corresponding license.
  3. 03

    Equipment Connection

    Link the plant's data sources.

    • Configure Modbus, OPC UA and PLC drivers.
    • Create and validate the tags for each device.
    • Verify real-time reads.
  4. 04

    History and Export

    Store the data and send it to other systems.

    • Configure cyclic archiving (historian).
    • Define retention and aggregations.
    • Export to OPC UA, MQTT or SQL Server.
  5. 05

    Dashboards and Reports

    Turn data into information for operations.

    • Design dashboards, trends and pivot tables.
    • Schedule PDF and email reports.
    • Configure alarms and alerts.
  6. 06

    Commissioning

    Validate the system and hand over a working platform with ongoing support.

    • Testing under real plant operating conditions.
    • Training for users and operators.
    • Definition of support and scalability.
