— OPC UA industrial connectivity

Kepware (KEPServerEX) is PTC’s industrial connectivity platform: a communications server that unifies access to plant data through more than 150 drivers and protocols. It supports OPC UA, OPC DA, Modbus, Siemens, Allen-Bradley, ABB, DNP3, IEC 60870 and many more, connecting multi-vendor PLCs, controllers, meters and devices in a single reliable, consistent and scalable data layer.

Its client/server architecture provides centralized configuration of channels, devices and tags, with built-in diagnostics, redundancy and OPC UA security. Kepware normalizes data and delivers it in real time to SCADA, HMI, historians, MES, ERP and analytics applications, eliminating dependence on proprietary drivers and simplifying OT/IT integration in Industry 4.0 projects.

Prerequisites

Before installing, define the infrastructure and validate the baseline requirements.

  • Windows server or VM sized to the number of tags.
  • Network connectivity to PLCs and field devices.
  • Inventory of the protocols, brands and models to integrate.

Server installation

Run the Kepware installer and select the drivers.

  • Install the server and the required driver suite.
  • Configure the server to start as a service.
  • Apply the license based on tag count.

Channels and devices

Configure communication with plant equipment.

  • Create channels per driver or field network.
  • Add devices by IP address, port or serial path.
  • Validate communication in the diagnostics view.

Tag definition

Expose the relevant process variables.

  • Create static tags and dynamic groups.
  • Define data types, scaling and addresses.
  • Organize tags by area and asset.

Security and OPC UA

Secure access to the exposed data.

  • Configure server users and permissions.
  • Enable secure OPC UA endpoints.
  • Manage certificates and encryption policies.

Verification and commissioning

Validate the system and bring the server into operation with hands-on support.

  • Check data quality with the OPC Quick Client.
  • Confirm service performance and stability.
  • Train users and define the support plan.
