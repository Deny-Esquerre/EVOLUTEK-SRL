N3uron is an Industrial Edge platform for IIoT & DataOps that connects the plant floor with business applications, on-premises or in the cloud. With a minimal footprint and a modular architecture, it acts as a bidirectional gateway that acquires data from PLCs and OPC servers, normalizes and contextualizes it, and distributes it to SCADA, MES, ERP or cloud services, serving as a single source of truth.

Its modules cover data acquisition (OPC UA/DA, Modbus, Siemens, IEC 104, REST, MQTT), data delivery (MQTT, OPC UA Server, REST, DNP3), and edge computing and visualization (Historian, Web Vision, alarms and scripting). Per-node licensing includes unlimited clients, tags, connections and devices, with secure TLS communication and automatic Store & Forward between nodes, so you can scale your architecture without data loss.

Prerequisites

Before installing, define the infrastructure and validate the baseline requirements.

  • Windows or Linux host, physical or virtual, with moderate resources.
  • Network connectivity to devices and cloud services.
  • MongoDB or SQL database for historical data storage.

Node installation

Install N3uron and get the node up and running.

  • Run the installer and configure the node service.
  • Define ports and startup mode.
  • Apply the license at the node level.

Web UI access

Log in to the web-based configuration interface.

  • Open the Web UI from any browser.
  • Create administrative users and roles.
  • Review the structure of the available modules.

Connecting data sources

Configure data acquisition from the plant floor.

  • Connect OPC UA/DA, Modbus, Siemens, IEC 104 or REST sources.
  • Create tags and contextualized data models.
  • Verify live readings from the Web UI.

Historian and visualization

Enable the data and presentation modules.

  • Configure the Historian on MongoDB or SQL.
  • Build HMI/SCADA screens with Web Vision.
  • Define alarms, notifications and scripts.

Verification and commissioning

Validate the system and bring the platform into operation with hands-on support.

  • Review logs, module status and connections.
  • Confirm data delivery and Store & Forward.
  • Train users and define the support plan.
