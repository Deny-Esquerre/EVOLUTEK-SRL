SCADA & HMI

Ignition by Inductive Automation is a modern SCADA, HMI and MES platform with an unlimited licensing model: no per-tag, per-client, per-device or per-designer fees. Because it is 100% web-based and cross-platform, you can build an application once and deploy it to any web browser, on-premises or in the cloud, with centralized updates and an IT-based architecture.

Its modular design combines the Platform module and OPC UA/DA drivers with visualization through Vision (plant-floor screens) or Perspective (responsive web-based HMI/SCADA), plus Tag Historian, Alarm Notification, Reporting and third-party modules. Ignition brings OT and IT together seamlessly, connecting PLCs, databases and services, and enabling scalable, secure applications with unlimited users for monitoring, control and operational efficiency.

Prerequisites

Before installing, define the infrastructure and validate the baseline requirements.

  • Server or VM running Windows or Linux.
  • Database for history storage and authentication.
  • Network connectivity and access to field devices.

Gateway installation

Install the Ignition Gateway and open the administration console.

  • Run the installer and configure the service.
  • Define ports and browser access.
  • Complete the initial Gateway setup.

Licensing and modules

Activate the license and install the required modules.

  • Install Platform, Vision or Perspective, Historian and Alarming.
  • Activate the server license.
  • Add reporting or third-party modules as the scope requires.

Connecting devices and tags

Integrate the equipment and define the tag structure.

  • Configure OPC UA/DA connections and device drivers.
  • Create and organize tags by area and process.
  • Enable tag history on the relevant tags.

Screen and alarm design

Build the visualization and event management.

  • Design screens in Vision or Perspective.
  • Configure alarms, alarm history and notifications.
  • Create trends and reports from historical data.

Verification and commissioning

Validate the system and bring the platform into operation with hands-on support.

  • Review client navigation, performance and security.
  • Confirm alarms, tag history and remote access.
  • Train users and define the support plan.
