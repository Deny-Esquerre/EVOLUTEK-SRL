FactoryStudio — SCADA, HMI and OEE

Tatsoft offers FactoryStudio powered by FrameworX, a SCADA/HMI platform for process visualization, control and monitoring. Its licensing model, with unlimited tags, displays and clients, lets you build complete applications —from machine-level HMIs to enterprise systems— with a single engineering environment and web or desktop deployment.

The platform natively integrates MQTT and Sparkplug B, OPC UA, dynamic tag connectivity and an ISA-95 asset tree, along with historian, alarms, reports, scripting and efficiency modules such as OEE to measure operational performance in real time. With edge computing capabilities and AI-ready features, FrameworX accelerates Industry 4.0 initiatives by connecting the plant floor with business information.

Prerequisites

Before installing, define the infrastructure and validate the basic requirements.

  • Windows server or VM sized for the project.
  • Network connectivity to PLCs and field devices.
  • Database for historian and alarms.

Environment Installation

Install FrameworX / FactoryStudio and get the environment up and running.

  • Run the product installer.
  • Define deployment paths and services.
  • Apply the corresponding license.

Project Creation

Configure the application and its base structure.

  • Create the project and define devices and modules.
  • Build the ISA-95 asset tree.
  • Configure databases and user security.

Device and Tag Connection

Integrate the equipment and define the tag structure.

  • Connect PLCs via OPC UA, MQTT or Sparkplug B.
  • Map tags dynamically or manually.
  • Configure redundant communication if required.

Displays, Alarms and OEE

Build the visualization and efficiency indicators.

  • Design process displays and synoptics.
  • Configure alarms, historian and reports.
  • Define KPIs and OEE monitoring.

Deployment and Commissioning

Validate the system and hand over a working application with ongoing support.

  • Deploy to web or desktop clients and verify performance.
  • Confirm alarms, historization and remote access.
  • Train users and define the support plan.
