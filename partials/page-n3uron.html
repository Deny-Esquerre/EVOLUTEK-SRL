Edge & MQTT

N3uron es una plataforma Industrial Edge para IIoT y DataOps que conecta el piso de planta con aplicaciones de negocio, en sitio o en la nube. Con una huella mínima y una arquitectura modular, actúa como gateway bidireccional que adquiere datos de PLCs y servidores OPC, los normaliza, contextualiza y los distribuye a SCADA, MES, ERP o servicios cloud, funcionando como una única fuente de verdad.

Sus módulos cubren adquisición (OPC UA/DA, Modbus, Siemens, IEC 104, REST, MQTT), entrega (MQTT, OPC UA Server, REST, DNP3) y edge computing y visualización (Historian, Web Vision, alarmas y scripting). El licenciamiento por nodo es ilimitado en clientes, tags, conexiones y dispositivos, con comunicación segura por TLS y Store & Forward automático entre nodos, lo que permite escalar arquitecturas sin pérdida de datos.

Requisitos previos

Antes de instalar, define la infraestructura y valida los requisitos base.

  • Host Windows o Linux, físico o virtual, con recursos moderados.
  • Conectividad de red hacia dispositivos y servicios cloud.
  • Base de datos MongoDB o SQL para historización.

Instalación del nodo

Instala N3uron y deja el nodo operativo.

  • Ejecutar el instalador y configurar el servicio del nodo.
  • Definir puertos y modo de arranque.
  • Aplicar la licencia a nivel de nodo.

Acceso a la Web UI

Ingresa a la interfaz web de configuración.

  • Abrir la Web UI desde cualquier navegador.
  • Crear usuarios y roles de administración.
  • Revisar la estructura de módulos disponibles.

Conexión de fuentes de datos

Configura la adquisición desde el piso de planta.

  • Conectar OPC UA/DA, Modbus, Siemens, IEC 104 o REST.
  • Crear tags y modelos de datos contextualizados.
  • Verificar la lectura en vivo desde la Web UI.

Historian y visualización

Activa los módulos de datos y presentación.

  • Configurar el Historian sobre MongoDB o SQL.
  • Construir pantallas HMI/SCADA con Web Vision.
  • Definir alarmas, notificaciones y scripts.

Verificación y puesta en marcha

Valida el sistema y deja la plataforma operativa con acompañamiento.

  • Revisar logs, estado de módulos y conexiones.
  • Confirmar entrega de datos y Store & Forward.
  • Capacitar a los usuarios y definir el soporte.
