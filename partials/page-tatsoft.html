Tatsoft ofrece FactoryStudio powered by FrameworX, un entorno SCADA/HMI para visualización, control y monitoreo de procesos. Su modelo de licenciamiento ilimitado en tags, pantallas y clientes permite construir aplicaciones completas —desde HMI de máquina hasta sistemas empresariales— con un único entorno de ingeniería y despliegue web o de escritorio.

La plataforma integra de forma nativa MQTT y Sparkplug B, OPC UA, conectividad dinámica de tags y un árbol de activos ISA-95, además de historian, alarmas, reportes, scripting y módulos de eficiencia como OEE para medir el desempeño operativo en tiempo real. Con capacidades de edge computing y funciones listas para IA, FrameworX acelera iniciativas de Industria 4.0 conectando el piso de planta con la información de negocio.

Requisitos previos

Antes de instalar, define la infraestructura y valida los requisitos base.

  • Servidor Windows o VM con recursos según el proyecto.
  • Conectividad de red hacia PLCs y dispositivos de campo.
  • Base de datos para historian y alarmas.

Instalación del entorno

Instala FrameworX / FactoryStudio y deja el entorno operativo.

  • Ejecutar el instalador del producto.
  • Definir rutas y servicios de despliegue.
  • Aplicar la licencia correspondiente.

Creación del proyecto

Configura la aplicación y su estructura base.

  • Crear el proyecto y definir dispositivos y módulos.
  • Estructurar el árbol de activos ISA-95.
  • Configurar bases de datos y seguridad de usuarios.

Conexión de dispositivos y tags

Integra los equipos y define la estructura de tags.

  • Conectar PLCs por OPC UA, MQTT o Sparkplug B.
  • Mapear tags de forma dinámica o manual.
  • Configurar comunicación redundante si aplica.

Pantallas, alarmas y OEE

Construye la visualización y los indicadores de eficiencia.

  • Diseñar pantallas de proceso y sincópticos.
  • Configurar alarmas, historian y reportes.
  • Definir KPIs y el monitoreo de OEE.

Publicación y puesta en marcha

Valida el sistema y deja la aplicación operativa con acompañamiento.

  • Desplegar en web o cliente y verificar el desempeño.
  • Confirmar alarmas, historización y acceso remoto.
  • Capacitar a los usuarios y definir el soporte.
